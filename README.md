# Stage 3: Concept Generation — interactive overview

Group project for *Transport Innovation and Valorisation* (UHasselt): second-hand e-bike battery health.

This page walks through how our 80 raw ideas became 39 concepts, a mind map of 3 groups and 12 sub-groups, and finally 5 candidate concepts for Stage 4.

Revised 2026-11-23: 10 sub-branches, 3 candidate concepts.

**View it:** https://cagehong.github.io/tiav-stage3-concepts/

Controls: click, Space or → for the next step; ← to go back; End to skip to the interactive view; Home to restart.

Files: `index.html` (page), `data.js` (ideas, concepts and candidates). Libraries (GSAP, d3) and fonts load from CDNs, so an internet connection is needed.
